# C-Bone-UCL.github.io

Source for my personal site: https://c-bone-ucl.github.io

It's built with [Hugo](https://gohugo.io) (extended, v0.140.2). To preview it locally, install Hugo and run `hugo server` from the repo root, then open http://localhost:1313. Every push to `main` triggers a GitHub Action that builds the site and publishes it to the `gh-pages` branch.

## Where things live

- `content/authors/admin/_index.md`: profile, links and the About text
- `content/gallery/`: the Research cards
- `content/news/`: news items, one folder each
- `content/publications/`: papers, one folder each
- `static/posters/`: poster PDFs linked from news items and Research cards
